# WebPC desktop

Hallmark direction: a live Workbench, utilitarian and modern, preserving the site's Inter, JetBrains Mono, cyan accent, dark/light tokens. The desktop uses actual window controls rather than decorative browser chrome. Edge-aligned site navigation and a functional bottom taskbar replace a marketing header/footer. Quiet nested geometric lines give the wallpaper its own identity without competing with working windows.

App registry: `src/scripts/pc/registry.mjs`. Add working same-origin app routes and their icons. Iframe apps are created only on launch, preserved on minimize, and cached invisibly on close so pending saves can finish. Before closing, the shell calls optional `iframe.contentWindow.pcBeforeClose()` synchronously; a false result keeps the window visible so the app can explain/export unsaved work. Closing removes the taskbar item; reopening reuses the same iframe. Each app owns persistent data and announces readiness with `{type: 'pc:ready', appId}` to the parent using `location.origin`. The parent verifies both origin and iframe source. The parent sends `{type: "pc:theme", theme: "light" | "dark"}` after readiness and theme changes. Optional `pc:focus` uses the same envelope; same-origin pointer/focus listeners also raise the app window.

`window-state.mjs` contains DOM-free geometry and lifecycle transitions. `desktop.js` owns DOM views without recreating live iframes on ordinary state changes. Mobile windows fill the workspace and retain desktop geometry when returning to a wider viewport. Desktop shortcuts open on double-click or native keyboard activation; coarse pointers use one tap. The launcher opens with a single activation.

Focus: visible keyboard rings; title bars support arrow-key movement and Shift+arrow resize, resize grip supports arrow keys. Minimize returns focus to the taskbar, close returns to the next window or its desktop icon. Windows are non-modal, so the desktop and taskbar remain accessible.

Save wording belongs to the installed app's capabilities. Local storage is device/browser-specific and can be cleared; exporting important work is the backup path. No server sync or installability is implied.

WebPC keeps the original `/pc/` routes, `pc:*` message contract, and saved-data keys for compatibility. The launcher filters registered apps by title, description, category, and keywords. Search uses all entered words; Enter launches the first result, ArrowDown focuses it, and Escape returns focus to Apps. Desktop shortcuts and launcher results scroll within the available viewport as the catalog grows. Register only usable apps, and distinguish external links from embedded tools.
