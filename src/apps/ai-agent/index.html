Your local workspace

The model and conversation run in this browser. Load model downloads about 600 MB–1.4 GB from Hugging Face, plus the local runtime. Cached weights may be reused. A compatible WebGPU device and enough memory are required.

Stop, New chat, and changing the model unload the current worker to cancel downloads and computation immediately. Load again to continue; downloaded cache files are kept. Closing the app also ends its worker.

Image input

Qwen models can read images. With Image input on, you can attach a PNG, JPEG or WebP of up to 10 MB; it is decoded and downscaled (longest side 768 px) in your browser before it reaches the model. The vision encoder downloads only when image input is first used — about 62 MB for the 0.8B model and about 197 MB for the 2B model. LFM3 is text-only and cannot use Image input. Attached images are not saved: the conversation keeps a text marker (for example [image: chart.png, 768×512]), so images are gone after a reload.

Web tools

Wikipedia search sends the search terms to Wikipedia. Page reading sends a request to the named site, without cookies. JavaScript runs in a fresh isolated sandbox with network access blocked.

Off by default. If direct reading fails, this sends the requested URL (including its query string) to Jina. Do not enable it for private or sensitive URLs. This choice lasts only until the app closes.

Conversation and recovery

Local saves can be removed by your browser. Export important chats. New chat and Open backup keep one previous stored record. Older voice-agent records are copied on the same origin, never deleted. A different website origin cannot read the old app’s storage: export there and open the backup here.
